# Технические решения

Записываем здесь решения, которые влияют на архитектуру проекта, и коротко объясняем причины.

## 2026-09-24 — Первый стек проекта

**Решение:** Python + FastAPI + PostgreSQL для backend; React + TypeScript для frontend.

**Причина:** стек соответствует текущим навыкам автора и востребован для backend/full-stack стажировок. React и TypeScript развивают нужный для рынка фронтенд-минимум.

## 2026-09-24 — Мышцы упражнений не входят в MVP

**Решение:** поля `primary_muscles` и `secondary_muscles` пока не добавляются.

**Причина:** каталог упражнений остаётся отдельной сущностью, поэтому позже можно добавить таблицы `muscles` и `exercise_muscles` с ролью `primary` или `secondary` через миграцию БД, не ломая тренировочные данные.
