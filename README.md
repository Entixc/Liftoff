# Workout Tracker

Веб-приложение для ведения дневника силовых и домашних тренировок.

Пользователь запускает тренировку, добавляет упражнения и подходы, а затем сохраняет результат в истории. Полная спецификация MVP находится в [docs/PROJECT_SPEC.md](docs/PROJECT_SPEC.md).

## Планируемый стек

- Backend: Python, FastAPI, PostgreSQL
- Frontend: React, TypeScript
- Инфраструктура: Docker, GitHub Actions

## Статус

Проект находится на этапе проектирования MVP.
